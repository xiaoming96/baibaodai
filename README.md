# 奇妙口袋事务所

Vue 3 + Vite 的原创童年治愈互动 Web MVP。无需注册，使用本地原创内容库；没有任何第三方 AI、官方 IP 图片或外部字体请求。

## 本地开发

需要 Node.js 20.19+ 或 22.12+（当前环境为 24.19.0）。

```bash
cd /workspace/baibaodai
npm ci --cache /tmp/baibaodai-npm-cache --no-audit --no-fund
npm run dev -- --port 5173
```

Vite 监听 `0.0.0.0`。生产构建与玩法测试：

```bash
npm test
npm run build
npm run preview -- --port 4173
```

`dist/` 可部署到任意静态站点服务，无后端或密钥依赖。

## GitHub Pages

仓库已包含 `.github/workflows/pages.yml`。在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。推送到 `main` 后，工作流安装依赖、运行玩法测试、构建并部署。

部署构建设置 `VITE_BASE_PATH=/baibaodai/`，网页资源与离线缓存会使用正确的仓库子路径。正常开发仍默认使用 `/`。发布成功后，网站地址为 `https://xiaoming96.github.io/baibaodai/`；是否已成功发布应以 GitHub 的部署结果和实际访问为准。

## 已实现

- 100 字烦恼输入、示例提示、3 秒翻找仪式、10 种原创杂物。
- 16 件原创道具及 SVG 插画，按关键词匹配；连续力度滑块对应三个概率区。
- 四类结局、30% 临场事件和 20% 连锁剧情；事件影响最终文案，连锁剧情匹配新的补救道具。
- 每日游客额度：3 次求助、1 次盲盒、1 次合体。图鉴中直接使用道具同样消耗求助额度。每日盲盒支持重复查看当日同一份运势。
- 两件已发现道具合体，10% 失败概率，8% 成功后传说道具概率；成功道具进入收藏。
- 道具图鉴、可读的乌龙事件簿、6 项成就；使用消耗耐久，作死区消耗翻倍，损坏后 24 小时自动恢复，每天一次免费修理。
- 三种可编辑明信片模板、860 × 1200 PNG 导出。支持浏览器原生文件分享；不支持时提示保存后手动分享。
- 当前浏览器本地存档、自然日额度刷新、关闭默认音效与音效开关、移动适配和减少动态效果设置。
- 生产构建自动缓存首页和全部基础资源；通过 HTTPS（或本机）访问一次后可离线重新打开并试玩。开发模式不注册 Service Worker。

## 概率与存档约定

原 PRD 的作死区权重 `10 / 20 / 70 / 10` 合计 110。本版保留比例并归一化，实际约为 `9.09% / 18.18% / 63.64% / 9.09%`；稳妥区和常规区按原值执行。力度区间为 `0–33 / 34–66 / 67–100`。

游客次数按浏览器本地自然日重置。数据使用 `localStorage` 键 `wonder-pocket:v1`，仅保存在当前设备和浏览器。存储不可用时仍可试玩，界面会提示无法保存。清除网站数据会清空记录；本地额度不能作为付费权限的安全校验。

## 后续接入范围

当前内容生成是本地规则与原创文案，合体同样使用本地组合逻辑。真实模型调用、用户提交脑洞、手机号/微信登录、云同步、会员支付、供应链订单、付费修理、微信 JS-SDK 和服务端权限校验尚未接入，页面没有模拟交易入口。上线这些能力需单独实现服务端、配置相应凭据及服务。

## 验证

`npm test` 使用 Node 内置测试，覆盖概率边界、事件和连锁阈值、额度、24 小时耐久恢复、每日修理、存档损坏与往返、合体失败及成就。

云环境提供 Python Playwright 和 Chromium 时，运行下面的真实浏览器回归（先启动开发服务）：

```bash
python tests/smoke.py
```

生产构建的离线验证（先在另一终端运行 `npm run preview -- --port 4173`）：

```bash
POCKET_TEST_URL=http://127.0.0.1:4173 POCKET_TEST_OFFLINE=1 python tests/smoke.py
```

浏览器测试覆盖空输入、求助到结局、海报图片下载、每日运势重访、图鉴与事件持久化、合体和次数限制、320/375/768px 响应式。它使用独立浏览器上下文，不会改变已有游客存档。截图及下载验证结果写入 `/tmp/pocket-smoke/`。
