# 功能说明与接入状态

本仓库已从本地游客玩法扩展为 Vue 前端与 Node.js 24 / SQLite 后端。这里区分可以直接使用的静态功能、已实现且有测试覆盖的后端能力，以及正式运行需要准备的外部服务。

公开前端地址为 **[https://xiaoming96.github.io/baibaodai/](https://xiaoming96.github.io/baibaodai/)**。当前没有正式后端主机、短信账号、微信应用、AI 服务凭据、收单商户或印刷供应链配置。浏览网站不会因此自动获得真实云登录、支付或配送能力。

## 玩法规则与数据边界

### 力度与概率

滑块区间为 `0–33 / 34–66 / 67–100`。按顺序抽取正常、小乌龙、大翻车、意外惊喜：

| 力度区 | 正常 | 小乌龙 | 大翻车 | 惊喜 |
| --- | ---: | ---: | ---: | ---: |
| 稳妥区 | 70% | 25% | 0% | 5% |
| 常规区 | 40% | 40% | 15% | 5% |
| 作死区 | 约 9.09% | 约 18.18% | 约 63.64% | 约 9.09% |

PRD 作死区的 `10 / 20 / 70 / 10` 总计 110；实现保留四项比例并归一化。临场事件 30%、连锁剧情 20% 为另外的抽取。合体失败概率 10%；本地合体成功后，有 8% 概率成为传说道具。

### 每日额度、分享和耐久

| 身份 | 求助 | 盲盒 | 合体 | 道具坏掉后自然恢复 |
| --- | ---: | ---: | ---: | --- |
| 游客 | 3 | 1 | 1 | 24 小时 |
| 注册账户 | 5 | 2 | 2 | 24 小时 |
| 月卡会员 | 不限 | 不限 | 不限 | 12 小时 |

游客使用浏览器本地自然日；云端按 `Asia/Shanghai` 的自然日校验。图鉴中直接启动道具也消耗求助额度。正常使用消耗 1 点耐久，作死区消耗 2 点；损坏道具需等待恢复或修理。

每个自然日有一次免费修理。原生分享成功后可获得额外修理机会，每天最多领取两次，未使用额度可以保留；下载海报、不支持分享或用户取消均不计奖励。前端只能知道系统分享面板是否成功完成，不能证明已发给某位好友；服务端仍限制账户每日奖励次数。

### 年度限定窗口

| 主题 | 每年开放日期（公历，含首尾日） | 主题价格 |
| --- | --- | ---: |
| 六一时光口袋 | 5 月 28 日至 6 月 3 日 | 6 元 |
| 新春暖暖口袋 | 1 月 20 日至 2 月 28 日 | 6 元 |
| 心意邮局口袋 | 2 月 10 日至 2 月 16 日 | 6 元 |

新春主题是年度公历促销季，没有按农历自动推算春节日期。预览不会赋予限定道具使用权；权益只能由经过校验的付款记录激活。

### 商店价格与付款边界

月卡默认 9.9 元 / 30 天；钥匙扣 19.9 元、冰箱贴 14.9 元、明信片套装 29.9 元、桌面立牌 24.9 元。会员实物八折；快速修理默认 1 元，其价格可由服务端运营配置调整。金额以服务端商品定义和订单为准，客户端无权提交自选金额。

付款适配器、签名通知和供应链协议已实现。验证付款通知后才激活权益或提交实物订单；通知去重、退款重算和发货幂等都有测试覆盖。项目没有自行发起商户退款或自动取消已生产商品的接口，实际退款与供应商取消仍需要运营流程。详细协议统一见 [部署文档](DEPLOYMENT.md#7-支付适配器通知和退款)。

### 游客、账户与备份

游客主存档使用 `wonder-pocket:v1`，脑洞草稿独立保存在当前浏览器；账户云存档与游客存档分开。游客清除网站数据前应导出 JSON 备份，文件上限为 1 MB。导入先完整校验，再合并进已有收藏，不会凭导入文件恢复购买权益或账户会话。

向账户迁移时，[guestTransfer.js](../src/lib/guestTransfer.js) 仅发送可校验的基础目录收藏、心选、偏好与历史摘要，并把请求压缩到 API 请求体限额以内。自定义合体道具、未知 ID、游客次数、会员和节日权益不会成为云端授权依据。完整本地合体内容仍保留在独立游客存档，退出登录可继续查看，也可从游客模式导出备份；登录后的账户备份只反映当前账户数据。

SQLite 保存服务端用户、玩法 JSON、订单、投稿、会话摘要和统计。浏览器文件备份用于玩法迁移；服务器持久卷备份用于恢复账户、付款与订单账本，两者用途不同。服务器部署和备份方式见 [部署文档](DEPLOYMENT.md#2-docker-后端)。

## 如何验证

```bash
npm ci --no-audit --no-fund
npm test
npm run build
```

游客浏览器回归需要先启动本地前端；标准开发联调同时运行 `npm run server` 与 `npm run dev -- --port 5173`：

```bash
python tests/smoke.py
```

隔离的云端浏览器回归自行启动并停止测试后端和 Vite：

```bash
python tests/cloud-smoke.py
```

该脚本使用测试专用短信夹具与真实 HTTP/SQLite 业务代码，没有拨通真实短信、微信、AI、支付或配送账号。测试通过代表实现和受控流程得到验证；真实生产供应商仍需按 [部署文档](DEPLOYMENT.md#9-上线验证与当前边界) 完成接入验证。

生产离线测试先运行 `npm run preview -- --port 4173`，再执行：

```bash
POCKET_TEST_URL=http://127.0.0.1:4173 POCKET_TEST_OFFLINE=1 python tests/smoke.py
```
